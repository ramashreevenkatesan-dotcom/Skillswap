Peer-to-Peer Process Architecture

How SkillSwap Works

A transparent 7-stage peer learning lifecycle designed for college collaboration and verified skill mastery.

01
Stage 1 • Identity & Security

Account Creation & Authentication

Students securely establish an academic identity with campus credentials, strong password hashing, and session authentication.

1. Open SkillSwap Portal
2. Enter Student Details
3. Server-side Regex Validation
4. Cryptographic Password Hash
5. Persist User in SQLite DB
6. Secure Session Login
02
Stage 2 • Educational Preferences

Profile Setup & Curriculum Wishlist

Define university major, learning interests, teaching readiness, availability slots, and mode preferences (Online, In-Person, or Hybrid).

1. Add Institution & Major
2. Select Learning Wishlist
3. Publish Teaching Syllabus
4. Set Availability Windows
5. Select Language & Mode
6. Save to SQLite Profile
03
Stage 3 • Catalog Exploration

Skill Discovery & Filtering

Students browse the live peer teaching catalog. Advanced multi-parameter filters enable finding mentors by programming language, UX tools, or experience levels.

1. Open Learn Catalog
2. Real-time Keyword Search
3. Category & Level Filters
4. Inspect Syllabus & Outcomes
5. View Verified Peer Ratings
6. Send Learning Request
04
Stage 4 • Reciprocal Synergy Engine

Rule-Based Bilateral Skill Matching

Our deterministic matching algorithm cross-references user catalogs. When User A teaches what User B wants and User B teaches what User A wants, a Strong Reciprocal Match is formed with clear explanations.

1. Retrieve Active Teaching Skills
2. Retrieve Learning Interests
3. Compare Complementary Matrix
4. Calculate Compatibility Score
5. Display Transparent Rationale
6. Propose Reciprocal Exchange
05
Stage 5 • Finite State Machine

Request Lifecycle & Authorization

State transitions (Pending → Accepted / Rejected / Cancelled → Completed) are enforced with strict authorization checks. Only recipient can accept; only sender can cancel pending proposals.

1. Proposal Logged as Pending
2. Recipient Notified on Dashboard
3. Recipient Accepts or Rejects
4. Atomic SQLite DB Update
5. Exchange Becomes Active
6. Sessions Unlocked
06
Stage 6 • Peer Coordination

Session Scheduling & Execution

Accepted peers use the built-in session scheduler to coordinate video meeting links, campus room reservations, and preparation agendas.

1. Open Session Scheduler
2. Set Date, Time, Duration
3. Attach Video / Room Link
4. Peer Session Conducted
5. Code & Concepts Exchanged
6. Exchange Marked Completed
07
Stage 7 • Quality Assurance

Peer Rating & Reputation Building

To eliminate fraudulent or fake reviews, reviews are unlocked ONLY after an exchange reaches the Completed state. Ratings directly compute the teacher's profile trust score.

1. Completed State Validated
2. Star Rating Selected (1-5)
3. Detailed Peer Comment
4. Atomic Review Persistence
5. Recalculate Average Rating
6. Display on Public Profile
